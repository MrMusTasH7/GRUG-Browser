# GRUG-Browser
This is GRUG Browser, a streaming focused app with bonus features for a small audience that was only supposed to conatin myself. It was made with Claude AI, so if you don't like that, then you can leave now, but I can promise fast speeds and low memory usage.

This is a Web Browser that I made because I have been using different browsers for a long time, and they all have their pros and cons, but I find that they all have one thing in common, they're slow, and inefficient, in one way or another. I've made GRUG Browser specifically for the purpose of speedy and low-resource streaming, however it's still pretty good for other usages too. So that this was possible and made to be the best that it possibly can be, I used Claude AI, however I'd like to also add that I am as a rule against AI, but occasionally I decide to use it for certain unachievable tasks, and as a random person who doesn't know how to code, or have a lot of money, I gave in so I can still have a good browsing experience. This might not be for everyone, but it has everything that I could ever want, so oyu can enjoy it with me if you'd like, or just ignore it and use your own browsers.
